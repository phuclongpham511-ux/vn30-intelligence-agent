# SStock product comparison — V4

SStock's researched public information architecture and financial task coverage
remain the benchmark. Its values, proprietary code and branding are not inputs.
Statuses below describe bounded data/functionality, not universal issuer coverage.

| Financial task | V4 improvement over V3 | Acceptance / remaining gap |
|---|---|---|
| Overview/highlights | Five reviewed issuers; source/accounting counts; survives missing market identity | Desktop TCB/FPT verified; surrounding company/quote context absent |
| Revenue/profit | FPT original 2022–24; MWG original 2024; existing HPG/bank panels reused | Desktop charts/navigation verified; more original quarters and years needed |
| Growth | Existing formulas; explicit whole-period histories; cross-document comparisons withheld | FPT 2024 and bank 2025 supported; earlier comparable-document coverage incomplete |
| Balance sheet | FPT three years, TCB three years, MWG closing 2024 | Desktop TCB navigation and FPT original table verified; opening MWG column never relabelled prior closing |
| Cash flow | FPT three years; TCB three years; MWG current 2024 with exact identities | Desktop signed TCB series verified; broader original quarters needed |
| Profitability | FPT 2024 average-balance ROE/ROA and turnover; existing bank returns | Desktop TCB missing historical ratios remain dashes; no invented annualization |
| Financial health | Existing liquidity and bank credit groups retained; FPT/MWG amounts/ratios where supported | Desktop TCB bank charts verified; no invented NIM/CAR/vendor CASA |
| Valuation | Dated FPT EPS/BVPS/input table, money/share unit separation | Desktop verified; P/E/P/B/earnings yield remain unsupported |
| Statement tables | Longer reviewed FPT/TCB histories, source dates/units, actual share counts, per-period original link | Desktop FPT statement switching verified; full note coverage/vintage comparison UI incomplete |
| Industry analytics | Ten saved issuers within observed SSI categories; explicit sample scope | No historical totals or qualified all-industry rankings |
| Peer comparisons | Two-company / covered-sample / individual labels; remove misleading ranks/percentiles | Desktop 2/22 bank coverage and 1/22 credit-note case verified; bank sample remains two |
| Dividends | Existing FPT three official notices remain reachable despite absent market identity | Desktop shortcut/dates/terms verified; broader histories and qualified ex-dates/yield missing |

Shared reporting-frequency, source, unit and historical-count controls, existing
charts, dense tables and Woofi navigation are reused. V4 adds no decorative
module to inflate coverage. Mobile visual acceptance, hover-tooltip interactions,
exhaustive error-state interactions and broad cross-issuer browser acceptance
remain PENDING. EN/VI and unavailable-view contracts/rendering pass separately.
