Activation never copies original-report metadata into a VCI/CafeF packet. The
source selector chooses whole packets; all original saved provider bytes remain
unchanged. The reviewed annual files and source revisions remain separately
identifiable. A corrupt preferred file fails explicitly, without silent fallback.

## Safe product behavior

Display each metric using its own inputs and quality. Unknown fields stay null,
not zero; unrelated missing metadata cannot blank a valid reported source fact.
Original document units, fiscal boundaries and scope qualify only those reviewed
cells and calculations. Derived results require compatible scope/source/periods
and applicable statement checks. Missing publication time limits point-in-time
use, not authorized current private amounts. Public consumers reject all private
payloads; financial verification is never a permission grant.

The financial UI uses Woofi branding/components and the existing SStock research
catalogue for task navigation, period selection, dense tables and source details.
No proprietary code/branding or paid dataset is copied. Four panels and the
existing statement/dividend/industry views are reused rather than decorated with
unsubstantiated metrics.
