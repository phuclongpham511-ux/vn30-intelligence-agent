# Licensing and access findings

Software licenses and financial-data rights are separate. The three candidate client libraries advertise Apache-2.0 code licenses. Neither this license nor anonymous endpoint availability grants Woofi commercial data redistribution rights. vnfin explicitly describes provider data as personal/internal research absent a redistribution license; vietfin describes personal/research/educational use. Those statements are recorded as source documentation, not a legal determination.

The TiniX dataset card specifies CC BY-NC 4.0; it is not used in commercial implementation. The annual-report collection describes issuer PDFs, checksums and an index; its LICENSE could not be verified at the requested URL. Original issuer/exchange/depository disclosures are preferred for financial truth, but public availability is not converted into an unrestricted republication grant.

SStock authentication was respected; WiData was inspected only through public UI and methodology. No restricted records, credentials, account session, scraped dataset, PDF corpus or provider raw capture is shipped in the frontend. Existing source-rights guards and separate personal-research access remain intact. User authorization to research is not recorded as provider-issued public permission.
